## 📌 Sobre el Proyecto
Este repositorio contiene el código fuente en `C/C++`, los scripts de modelado y simulación en `MATLAB/Simulink`, y los informes correspondientes a los Trabajos Prácticos de la cursada. 

El objetivo principal de este proyecto es el modelado matemático, simulación e implementación en hardware de un sistema de control digital para estabilizar un sistema *ball & beam*.
